# 🏋️‍♂️ FitLab - Tienda de Suplementos y Ropa Deportiva

Este es un proyecto web orientado a fullstack II . Consiste en una plataforma e-commerce para la venta de productos fitness, ropa deportiva y suplementación.

##  Características de la Página

* **Catálogo de Productos:** Vista interactiva con productos fitness y botones de compra.
* **Carrito de Compras:** Modal funcional que acumula ítems y calcula el total.
* **Panel Administrador:** Tabla interactiva para la gestión de productos y stock.
* **Formulario de Contacto:** Sección con validaciones para registro y/o login.
* **Diseño Responsive:** Adaptado para dispositivos computadoras usando Bootstrap.

---

## Tecnologías Utilizadas

* **HTML5:** Estructura e interfaz semántica.
* **CSS3 & Bootstrap 5:** Diseños personalizados y componentes de interfaz.
* **JavaScript:** Lógica del carrito de compras y manipulación del DOM.
* **Git & GitHub:** Control de versiones y trabajo colaborativo.
